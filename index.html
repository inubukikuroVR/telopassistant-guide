GUIDE 01

まずはここから

アイコン付き字幕を、いつものAEで。

TelopAssistant は、ゲーム実況・配信切り抜き・VTuber／VRChat動画などの字幕制作を支援するAfter Effects用スクリプトです。文章は手入力し、話者画像と通常のテキストレイヤーを1セットで生成します。

最短の制作フロー

  1. 導入JSXを起動し、字幕を置くコンポジションを指定。
  2. 登録初期4書式を準備し、話者名と画像を登録。
  3. 生成話者・書式・サイズ・文章・表示秒数を指定。
  4. 調整テキストを直接編集。時間を変えたらアイコンを同期。
生成

文字幅に追従するアイコン付き字幕

書式

4つの初期書式＋オリジナル書式登録

演出

4種の動き。強さ・速度も調整可能

再利用

話者・書式を別々のXMLに保存

最初に用意するもの

After Effects、本体ファイル TelopAssistant.jsx、使用するフォント、話者アイコン画像。現行版は字幕生成に話者画像の登録が必要です。音声認識・自動文字起こしはありません。

読み方

まずは導入と字幕生成まで進めてください。編集・保存・トラブル対応は必要なときに参照できます。HTML版は左の目次と検索、PDF版は各ページの見出しから探せます。

GUIDE 02

導入と起動

ドッキングでも、単独ウィンドウでも。

おすすめ：ドッキングパネルとして起動

  1. 01AEの「ファイル → スクリプト → ScriptUIパネルをインストール」を選びます。
  2. 02TelopAssistant.jsx を選択します。作業中のAEPを保存し、AEを再起動します。
  3. 03「ウィンドウ → TelopAssistant.jsx」から開きます。
  4. 04パネルのタブをドラッグし、配置先が色付きになったところで離します。必要に応じてワークスペースを保存します。

単独ウィンドウで試す

「ファイル → スクリプト → スクリプトファイルを実行」からJSXを選択します。この起動方法はフローティング版です。ドッキングする場合は「ウィンドウ」メニューから開いてください。

インストール項目がない場合

AEの Scripts/ScriptUI Panels フォルダーへJSXを配置して再起動します。Windowsの例：Adobe After Effects [年版]/Support Files/Scripts/ScriptUI Panels。書き込み権限が必要な場合は、AEのインストール機能を利用してください。

小さなパネルで使う

右端の縦スクロールバーで下側の操作へ移動できます。幅は約320pxを目安にしてください。高さを変えるとスクロール範囲も更新されます。文章入力欄のスクロールは、パネル全体のスクロールとは別です。

更新版を入れるとき

インストール済みのJSXも更新し、パネルを一度閉じて開き直します。保存場所へコピーしただけでは、開いているパネルは旧版のままです。AEの更新で保存先フォルダーが変わる場合は再インストールしてください。

GUIDE 03

初回設定と字幕生成

文章を入れて、話者を選んで、生成。

初回設定

  1. 配置先字幕を置くコンポジションを開き、「配置先を指定 / 更新」を押します。
  2. 書式登録タブの「初期4書式を登録 / 更新」を押します。
  3. 話者名「話者を登録 / 画像を更新」で名前を入力します。
  4. 画像透過PNGなどのアイコン画像を選択します。
  5. 解像度続く選択画面で「300×300px以内に軽量化」または「そのままの解像度で使う」を選び、「登録」を押します。
話者名 → アイコン画像 → 解像度を選択

アイコンを軽量化しますか？

選択画面のイメージです。このガイド上での選択は、AEの設定を変更しません。

初期選択は300×300px以内に軽量化

縦横比を保ち、長辺が300px以内になるよう処理解像度を下げます。300px以下の画像は拡大しません。例：1500×1500px → 300×300px、1200×600px → 300×150px。正方形へ引き伸ばす処理ではありません。

表示サイズと元画像はそのまま

字幕上のアイコンの大きさは、これまでどおり文字サイズに連動します。軽量化では元ファイルを書き換えず、AE内の共有コンポジションを介して表示します。元画像と「TA アイコン300px …」コンポジションは、AEPの素材として保持してください。

そのままの解像度で使う場合

大きく表示するアイコンなど、細部を優先したいときに選びます。元画像の解像度で登録されます。キャンセルした場合は登録しません。

字幕を生成

設定するのはこの4つ

話者・書式・文章・表示秒数。文字サイズと動きは、必要なときに変更します。

画面は操作を説明する模式図です。実際のパネルには削除・登録・配置などの操作もあります。

1つの字幕を生成する

  1. 開始位置AEの再生位置を字幕の開始フレームへ合わせます。
  2. 内容話者・書式・文字サイズを選び、文章と表示秒数を入力します。改行も使えます。
  3. エフェクト必要なら動きを選択します。初期値はノーマル（未適用）です。
  4. 生成「字幕を生成」を押します。テキストとアイコンの2レイヤーが作られます。

生成時のルール

終了は現在位置＋指定秒数。コンポジションの終端を超える分は切り詰めます。話者とエフェクトの選択は維持されます。「生成後は①通常に戻す」がONなら書式は①通常へ戻ります。①通常がない場合は残った書式の先頭を使います。

GUIDE 04

書式とフォント

4つの初期書式を、場面に合わせて。

共通の初期設定

白塗り・黒ストローク12px。ルイカはサンプルと同じ09を使用します。文字サイズは見本の設定があれば引き継ぎ、通常の初期値は100pxです。フォントファイルは商品に含まれません。

文字サイズを変える

候補のプルダウンから選ぶか、入力欄へ1〜1296pxを自由入力します。既存字幕は選択し、サイズ欄の「適用」を押します。書式を選び直すと、その書式に保存された文字サイズが入力されます。

オリジナルの書式を登録

AEで見本のテキストを1つ作り、フォント・サイズ・塗り・ストロークを整えます。配置先を指定したまま見本を選択し、登録タブの「選択テキストから書式登録」を押します。同じ名前なら更新します。

登録済みの見本を編集

「スタイル見本をAEで開く」で設定コンポジションを開き、見本文字を編集します。影はドロップシャドウを使用してください。配置先へ戻って更新後、必要な字幕へ「書式を適用」します。既存字幕は自動では変わりません。

初期4書式を登録 / 更新

同名の初期4書式を初期設定へ戻します。追加したカスタム書式や作成済み字幕は変更しません。パネル内の書式プレビュー・塗り色変更UIは、現在の版にはありません。色はAEの文字パネルで変更してください。

GUIDE 05

編集とエフェクト

生成後も、普通のテキストとして編集。

操作早見表

やりたいこと操作
文章・フォント・色を変更AEのテキスト／文字パネルで編集
字幕を移動テキストレイヤーだけをドラッグ、または「位置」を変更
話者・書式を変更ペアの片方を選び、候補を選択して対応ボタンを押す
表示区間を変更テキストの開始・終了を調整後、「表示区間を同期」

アイコンは文字サイズに自動追従

アイコンの画像全体の高さは、先頭文字のフォントサイズ×1.4です。2行字幕でも行数で大きくなりません。文字の長さに合わせて位置が追従し、テキストの移動・位置キーフレームにも追従します。透明余白はあらかじめ画像側で揃えてください。

4種類の動き

エフェクト見え方
叫び細かく不規則な縦方向の震え
ゆる叫び小さく滑らかな不規則な揺れ
へにょへにょゆっくりした大きな波のうねり
ラジオ細かい横方向の波打ち

適用と調整

テキストかアイコンを選び、エフェクトと強さ・速度を指定して適用します。両方のレイヤーへ反映されます。0〜300%で調整でき、100%が標準、強さ0%は変形なし、速度0%は静止した変形です。値を変えたら再適用してください。

複数字幕への一括適用

変更する字幕のテキスト、またはアイコンをまとめて選択します。話者・書式・動き・サイズなどを一括変更できます。書式の再適用は字幕全体の文字装飾を置き換えるため、一部分だけ加えた装飾も変わります。動きは重ね掛けせず置き換えます。音声への加工は行いません。

GUIDE 06

保存・読み込み・削除

同じ設定を、別の制作でも使う。

AEPとXMLの役割

保存方法保存するもの
AEPを保存作成した字幕・登録した話者・書式・適用済みの動き
話者を書き出しその配置先の全話者の名前と画像を1つのXMLへ
書式を書き出しその配置先の全書式を別のXMLへ

別のAEPへ設定を持っていく

  1. 書き出し登録タブで、話者と書式をそれぞれ書き出します。例：話者.xml／書式.xml。
  2. 配置先移行先のコンポジションを開き、配置先を指定します。
  3. 読み込み「話者を読み込み」「書式を読み込み」で対応するXMLを選びます。
  4. 確認同名の登録は「名前 (2)」のように追加されます。既存登録と既存字幕は残ります。

話者XMLの横にできる .assets フォルダー

話者XMLには画像本体が入っています。読み込み時、XMLの横に画像を展開し、AEはその画像を参照します。読み込み後の .assets フォルダーは移動・削除しないでください。再読み込み時は別の展開フォルダーを作ります。

書式XMLに含まれるもの

フォント名・基本文字書式・最初のドロップシャドウ。フォントファイル、4種類の動き、任意のエフェクトやアニメーション、文字ごとに異なる装飾は含みません。移行先には同じフォントを用意してください。

画像の軽量化設定も引き継ぐ

現行版の話者XMLには元画像と、登録時に選んだ300px軽量化の設定も保存します。現行版で読み込むと同じ選択で復元します。軽量化設定がない旧XMLは、元の解像度で読み込みます。XML内の画像データ自体は元画像のため、300pxを選んでもXMLのファイル容量が小さくなるとは限りません。

登録の削除と画像更新

話者・書式の右の「削除」は登録だけを削除します。既存字幕と画像素材は残ります。同名の話者へ画像を再登録すると、その配置先の既存アイコンも更新します。削除してから同名で作り直した場合は別の登録になります。 同じ話者名で再登録する際も、300pxか元の解像度かを選び直せます。既存字幕にもその選択が反映されます。

保存時のポイント

設定は「字幕設定｜…」コンポジションに保存されるのでAEPも保存します。元画像も保持してください。別PCへAEPを渡す場合は素材を収集します。XMLの書き出しにはAE側でスクリプトのファイル書き込み許可が必要です。

現行版の範囲を、先に確認。

アイコンだけ表示時間がずれる

テキスト側を基準に時間を調整し、ペアの片方を選んで「表示区間を同期」を押します。レイヤーの端は常時自動同期ではありません。

フォントが見本と違う／文字が出ない

指定フォントがインストールされているか、使いたい文字がそのフォントにあるか確認します。初期フォントの対応名はフォント案内を参照してください。

300pxにすると表示が小さくなる？

なりません。処理解像度と、字幕上の表示サイズは別です。表示の高さは先頭文字のフォントサイズ×1.4を維持します。大きく拡大する場面では細部が変わることがあるため、必要なら元の解像度を選んでください。

重いときはどうすればよい？

まずは新しく登録する話者を300pxにします。既存の話者は同じ名前で再登録すると選び直せます。メモリ使用量・元動画・ほかのエフェクトも影響するため、軽量化だけで停止やクラッシュが必ず解消するわけではありません。

下側の操作が見えない

右端の縦スクロールバーを下げます。横幅も足りない場合はパネルを広げます。更新後は、インストール済みのJSXを更新してパネルを開き直してください。

既存字幕に変更が反映されない

見本の変更や数値入力だけでは既存字幕は更新されません。対象を選択して「書式を適用」「適用」などを押します。削除を取り消した後は、配置先を更新すると候補も更新されます。

複製・高度な装飾について

新しい字幕はパネルから生成してください。AEの通常の複製や別コンポジションへのコピーで作ったペアは対応対象外です。管理用のレイヤーコメントは変更しないでください。縦書き、パス上の文字、回転・3D、多重レイヤースタイルなどは初版の対応範囲外です。
